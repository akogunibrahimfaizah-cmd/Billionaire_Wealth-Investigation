# **BILLIONAIRE WEALTH INVESTIGATION USING SQL**



#### **Project Overview**

This project explores a dataset of the world's richest billionaires using SQL. The aim is to analyze billionaires wealth, age, country, and industry, and to identify patterns and insights from the data. 

**Dataset:** [View Wxcel Dataset](https://docs.google.com/spreadsheets/d/1Z9uQOhtrSTniTTu76Aic6oUDe30acfwB9GP6TqCoEGo/edit?usp=sharing).

The analysis was carried out using SQLite, with SQL queries written to answer business and data related questions.



## Dataset Description

The dataset contains 200 billionaire records and seven columns:

* Serial\_number - Unique serial number assigned to each record.
* Rank - Billionaire's position in the ranking.
* Name - Name of the billionaire.
* Age - Age of the billionaire
* Country - Country associated with the billionaire.
* Networth\_billion\_US\_dollars - Net worth in billions of US dollars.
* Industry - Industry in which the billionaire's wealth is associated.



#### **Tools Used**

* **DB Browse for SQLite -** Used to create and manage the database.
* **SQLite -** Used to write and execute SQL queries.
* **GitHub** - Used to document and share the project.



#### **Project Objectives**

The project focuses on answering questions such as:

1. Who are the 20 richest billionaires?
2. Who are the five youngest billionaires?
3. What are the average age and average net worth of the billionaire?
4. Which countries have the highest number of billionaires?
5. Which countries have the highest combined billionaire net worth?
6. Which industries have the highest number of billionaires?
7. Which countries have at least 5 billionaires?
8. What is the total net worth of billionaires below the age of 50?
9. Which billionaires have a net worth above the overall average?
10. Which industry have the highest average net worth?
11. Who are the 10 oldest billionaires?
12. How many billionaires are below the age of 40?
13. What is the highest billionaire net worth recorded in each country?
14. Which industries have an average net worth above $30 billion?
15. What is the difference between the highest and lowest net worth in the dataset?



#### **SQL Concepts Applied**

The project uses the following SQL concepts:

* SELECT and FROM
* WHERE
* ORDER BY
* ASC and DESC
* LIMIT
* Aggregate functions: COUNT(), SUM(), AVG(), MAX(), and MIN()
* GROUP BY
* HAVING
* Subqueries
